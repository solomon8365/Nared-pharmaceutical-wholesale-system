# Pharma Distribution System

A simple PHP-based pharmacy distribution management system scaffold.

## Features
- User authentication
- Product inventory management
- Supplier management
- Order creation with stock adjustments
- Dashboard summary

## Setup
1. Copy the project to your web server directory.
2. Create a MySQL database named `pharma`.
3. Import `sql/schema.sql` into the database.
4. Update `config.php` with your database credentials.
5. Visit `http://localhost/pharma project/index.php`.

## Default user
- Username: `admin`
- Password: `admin123`

> Replace the default password after first login.
